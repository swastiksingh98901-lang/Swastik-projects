# Swastik-projects
project_01.py

Purpose: Demonstrates list creation and basic list operations by modeling a small book library.
Features: add books with append(), remove a book, check membership, count total books, sort alphabetically.
How to run: python project_01.py
Notes: Illustrates basic CRUD operations on a Python list.
project_02.py

Purpose: Analyze an array of student test scores.
Features: finds highest/lowest scores, computes average, counts scores >80, lists scores above average, sorts and displays top 3, computes grade distribution (A–F).
How to run: python project_02.py
Notes: Useful for learning aggregations, comprehensions, and conditional counting.
project_03.py

Purpose: Manage a nested list acting as a category-based shopping cart.
Features: adds items per category, counts total items, finds category with most items, moves an item between categories, prints a receipt.
How to run: python project_03.py
Notes: Shows nested list indexing and a helper function move_item() for list manipulation.
project_04.py

Purpose: Simulate playlist operations and basic text-based searching.
Features: shuffle playlist, show recently played tracks, remove duplicates, backup copy, merge playlists, build a simple "smart playlist" by keyword.
How to run: python project_04.py
Notes: Demonstrates random.shuffle, set-based deduplication, and simple string matching.
project_05.py

Purpose: Analyze daily temperature data for statistical and pattern insights.
Features: hottest/coldest day, average temperature, days above average, categorize temps (cold/mild/warm), detect longest hot streak, detect anomalies (>5°F change).
How to run: python project_05.py
Notes: Good example of time-series basic analysis without external libraries.
project_05.1.py

Purpose: A variant/extension of project_05.py with similar temperature analysis and additional outputs such as day indices for hottest/coldest and anomaly lists.
Features: same categories, longest streak detection, anomalies reported by day number, and a clear statistical summary printout.
How to run: python project_05.1.py
Notes: Use this version if you prefer day-indexed outputs and a slightly different anomaly representation.
