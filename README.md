# Swastik-projects
Repository structure

project_01.py — simple library (book list) management demo using list operations.
project_02.py — test scores analysis: min/max, average, top scores, and grade distribution.
project_03.py — nested list (shopping cart) demo with category management and item moving.
project_04.py — playlist management: shuffle, deduplicate, merge, and simple search/smart playlist.
project_05.py — temperature-data analysis: hottest/coldest days, averages, streaks, anomalies.
project_05.1.py — alternate/extended temperature-data analysis with additional stats and anomaly detection.
Purpose / Learning outcomes

Practice Python lists and nested lists.
Use built-in functions like max, min, sum, sorted.
Implement list comprehensions and basic data grouping.
Work with simple algorithms like streak detection and anomaly detection.
Demonstrate readable, runnable scripts suitable for college submission.
